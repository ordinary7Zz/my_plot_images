分割 / 分类性能图生成说明

一、用途
- 生成分割任务的两种图：环形图（radial heatmap）、雷达图（radar）。
- 生成分类任务的两种图：环形图（radial heatmap）、雷达图（radar）。
- 分割指标：Dice、HD95。
- 分类指标：AUROC、AUPRC。
- 分类横向对比图（paired comparison）：AUROC。

二、对应文件
1) 分割配置文件
   - lp_radiomap_config.json
   - circular_map_seg_config.json

2) 分类配置文件
   - cls_metrics_config.json
   - circular_map_config.json

3) 环形图生成脚本
   - lp_radiomap_from_config.py

3.1) Circos 环形图生成脚本
   - circular_map_from_config.py

4) 雷达图生成脚本
   - seg_radar_from_config.py

5) 横向对比图生成脚本
   - paired_comparison_from_config.py

三、配置文件结构
1) 分割配置 lp_radiomap_config.json
   - datasets.dice         — Dice 指标（均值 + 置信区间）
   - datasets.hd95         — HD95 指标（均值 + 置信区间）

2) 分类配置 cls_metrics_config.json
   - datasets.auroc        — AUROC 指标（均值 + 置信区间）
   - datasets.auprc        — AUPRC 指标（均值 + 置信区间）

说明：
- 每个指标放在 datasets 下，通过 manual_values 字段提供绘图均值。
- 置信区间存放在 manual_confidence_intervals 字段（二维数组 [lower, upper]）。
- 当前环形图脚本（lp_radiomap_from_config.py）和雷达图脚本（seg_radar_from_config.py）
  都支持通过 --config 参数动态传入 JSON 配置文件，无需硬编码路径。

十一、后续只需要修改的内容
1) 改分割数值
   - lp_radiomap_config.json 中的：
     - datasets.dice.manual_values              （Dice 均值）
     - datasets.dice.manual_confidence_intervals （Dice 置信区间）
     - datasets.hd95.manual_values               （HD95 均值）
     - datasets.hd95.manual_confidence_intervals （HD95 置信区间）

2) 改分类数值
   - cls_metrics_config.json 中的：
     - datasets.auroc.manual_values              （AUROC 均值）
     - datasets.auroc.manual_confidence_intervals（AUROC 置信区间）
     - datasets.auprc.manual_values              （AUPRC 均值）
     - datasets.auprc.manual_confidence_intervals（AUPRC 置信区间）

3) 改显示顺序
   - 配置文件中的 plot.model_order （模型从外到内的排列顺序）
   - 各指标下的 category_map.Datasets （数据集在图上出现的顺序）

十二、注意事项
- 所有脚本都通过 --config 参数动态加载配置文件，不再硬编码路径。
- 如果 --output-dir 未指定，默认输出到配置文件中 paths.default_output_dir 指定的目录。
- 当前环形图对 HD95 指标自动做了 "lower_is_better" 处理（反向色阶）。
- 如果某个数据集的文件夹不存在，脚本会跳过并打印警告，不会中断其他数据集的生成。
